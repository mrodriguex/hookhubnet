Expose Local Services Securely

HookHubNet is a modern reverse-tunneling platform built with .NET and YARP. Create secure tunnels using subdomains — no port forwarding required.

Get Started View Source

Why HookHubNet?

Dynamic Subdomains

Each tunnel is mapped automatically using subdomain routing.

Built on YARP

High-performance reverse proxy using Microsoft YARP.

Zero Config Clients

No firewall rules or NAT configuration needed.

WebSockets Ready

Supports real-time protocols out of the box.

Interface Preview

Early-stage UI — evolving fast
